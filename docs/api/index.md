# API

API предоставляет доступ к функциям сервиса анализа тональности отзывов.

## Основные операции

- `POST /analysis` — проанализировать тональность отзыва;
- `GET /analysis/{id}` — получить сохранённый результат анализа;
- `GET /models` — получить список доступных ML-моделей.

## Основной запрос

Для анализа отзыва необходимо отправить `POST /analysis` с JSON-объектом:

```json
{
  "text": "Товар пришёл быстро, но упаковка была повреждена."
}
```

В ответе сервис возвращает тональность отзыва, уровень уверенности
модели, идентификатор результата и версию модели.

Уровень уверенности (`confidence`) передаётся числом от `0` до `1`.
Например, `0.87` означает 87% уверенности модели в результате.
Интерфейс может отображать это значение в процентах.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
