# Model Card

## Общая информация

**Название модели:** `cointegrated/rubert-tiny-sentiment-balanced`

**Источник:** [Hugging Face — cointegrated/rubert-tiny-sentiment-balanced](https://huggingface.co/cointegrated/rubert-tiny-sentiment-balanced)

**Автор / организация:** cointegrated

**Задача модели:** классификация тональности коротких русскоязычных текстов.

**Язык:** русский.

Модель является дообученной версией `cointegrated/rubert-tiny`
и решает задачу многоклассовой классификации: определяет, является
ли текст отрицательным, нейтральным или положительным. 

## Использование в проекте

Модель используется в сервисе «Анализатор отзывов» для определения
тональности отзыва пользователя.

После вызова `POST /analysis` текст отзыва передаётся ML-модели.
Модель возвращает одну из трёх категорий и вероятности классов.
Сервис выбирает наиболее вероятную категорию, рассчитывает уровень
уверенности, сохраняет результат и возвращает его пользователю
в ответе API.

Результат используется для быстрого анализа обратной связи:
отрицательные отзывы можно приоритизировать для ручной проверки,
а положительные и нейтральные — использовать в общей аналитике.

## Входные данные

Модель принимает короткий текст на русском языке, например отзыв
о товаре, услуге, фильме или организации.

В нашем проекте входом является поле `text` из JSON-запроса
`POST /analysis`.

Пример:

```json
{
  "text": "Товар пришёл быстро, но упаковка была повреждена."
}
```

## Выходные данные

Модель возвращает вероятности для трёх классов:

- `negative` — отрицательная тональность;
- `neutral` — нейтральная тональность;
- `positive` — положительная тональность.

В API сервиса возвращаются:

- `sentiment` — итоговая категория;
- `confidence` — уверенность модели в диапазоне от 0 до 1;
- `modelVersion` — версия используемой модели;
- `id` — идентификатор сохранённого результата анализа.

## Метрики качества

Авторы модели приводят Macro F1 на сбалансированных тестовых наборах:

| Источник данных | Macro F1 |
|---|---:|
| SentiRuEval2016_banks | 0.83 |
| SentiRuEval2016_tele | 0.74 |
| kaggle_news | 0.66 |
| linis | 0.50 |
| mokoron | 0.98 |
| rureviews | 0.72 |
| rusentiment | 0.67 |

Метрики показывают, что качество модели зависит от типа и источника
текстов: на отзывах `mokoron` результат высокий, а на данных `linis` —
заметно ниже.

## Ограничения

1. Модель предназначена для коротких русскоязычных текстов; её качество
   на длинных текстах или текстах на других языках авторами отдельно
   не подтверждено.
2. Модель обучалась на наборах данных из разных доменов, поэтому её
   качество различается между источниками: например, Macro F1 составляет
   0.98 на `mokoron`, но 0.50 на `linis`.
3. Модель определяет только три общие категории тональности и не различает
   более тонкие эмоции, например разочарование, радость, тревогу или сарказм.
4. Потенциальное ограничение для нашего проекта: модель может хуже работать
   на отзывах со специализированной терминологией, иронией, смешанной
   тональностью или очень короткими фразами. Это предположение требует
   отдельной проверки на данных проекта.

## Не рекомендуется использовать

Модель не рекомендуется использовать для:

- автоматического принятия важных решений без проверки человеком;
- анализа медицинских, юридических или финансовых текстов как единственного
  источника оценки;
- определения точной эмоциональной окраски, намерений автора или фактов;
- обработки текстов на языках, кроме русского, без предварительного тестирования.
