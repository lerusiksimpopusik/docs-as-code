# Анализатор отзывов

Сервис автоматически определяет тональность пользовательского отзыва:
положительная, нейтральная или отрицательная.

Пользователь отправляет текст отзыва, а ML-модель анализирует его
и возвращает предполагаемую тональность вместе с уровнем уверенности.
Результат можно использовать для быстрого анализа обратной связи
и приоритизации отрицательных отзывов.

Основные пользователи:

- пользователь;
- аналитик или сотрудник компании.

Основные функции:

- отправка текста отзыва;
- определение тональности отзыва;
- отображение результата и уровня уверенности;
- сохранение результата анализа.

## Комплект документации

1. **Описание проекта** — для всех участников команды; объясняет назначение и границы сервиса.
2. **Требования** — для аналитиков, разработчиков и тестировщиков; фиксирует User Stories, Use Case и критерии приёмки.
3. **Архитектура системы** — для разработчиков; описывает компоненты сервиса и их взаимодействие.
4. **Документация API** — для разработчиков и интеграторов; описывает запросы и ответы сервиса.
5. **Документация ML-модели** — для ML-инженеров; описывает данные, обучение, метрики и ограничения модели.
6. **Руководство пользователя** — для конечных пользователей; объясняет, как отправить отзыв и прочитать результат.
